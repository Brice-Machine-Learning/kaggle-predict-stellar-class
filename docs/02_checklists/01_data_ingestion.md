# Notebook 01 — Data Ingestion

**Notebook:** `01_data_ingestion.ipynb`
**Objective:** Understand the structure, contents, and integrity of the supplied datasets before analysis.

> Self-study checklist. No implementation code or preselected modeling solution is provided.

## Checklist

### Load and inspect

- [ ] Load the training, testing, and sample submission datasets.
- [ ] Determine the number of rows and columns in each dataset.
- [ ] Inspect the first and last few records.
- [ ] Identify column names and data types.
- [ ] Identify the target variable and unique identifier.
- [ ] Confirm which columns are shared between training and testing data.

### Data quality

- [ ] Determine whether any values are missing.
- [ ] Calculate missing-value counts and percentages by column.
- [ ] Check for duplicate records and duplicate identifiers.
- [ ] Inspect numeric columns for invalid or infinite values.
- [ ] Identify unexpected data types or suspicious values.
- [ ] Confirm that the target contains GALAXY, STAR, and QSO.

### Documentation

- [ ] Record the original dataset dimensions.
- [ ] Create an initial data dictionary.
- [ ] Document apparent data-quality issues.
- [ ] Confirm the expected submission format.
- [ ] Preserve the original raw data without modification.
