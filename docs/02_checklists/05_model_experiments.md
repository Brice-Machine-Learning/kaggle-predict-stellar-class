# Notebook 05 — Model Experiments

**Notebook:** `05_model_experiments.ipynb`
**Objective:** Test hypotheses systematically and compare candidate models fairly.

> Self-study checklist. No implementation code or preselected modeling solution is provided.

## Checklist

### Plan experiments

- [ ] Review baseline performance and errors.
- [ ] Formulate a hypothesis for each proposed improvement.
- [ ] Select a small number of candidate algorithms.
- [ ] Define a consistent validation procedure.
- [ ] Choose the primary comparison metric.
- [ ] Decide which experiment details to record.

### Conduct experiments

- [ ] Compare alternative classifiers.
- [ ] Investigate scaling where relevant.
- [ ] Test selected engineered features.
- [ ] Consider class weighting if class-wise performance differs.
- [ ] Experiment with hyperparameter tuning.
- [ ] Record cross-validation performance and variability.
- [ ] Track training time and complexity.

### Evaluate improvements

- [ ] Compare against the baseline.
- [ ] Check whether gains are consistent across folds.
- [ ] Check whether improvements benefit all classes.
- [ ] Identify overfitting.
- [ ] Avoid repeatedly tuning against a final holdout set.
- [ ] Document unsuccessful experiments.
- [ ] Select a final candidate based on reliable evidence.
